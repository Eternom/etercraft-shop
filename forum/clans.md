=== Présenter son clan : le modèle | épinglé, verrouillé

Ce forum sert à **recruter** pour ton clan, ou à trouver celui qui te correspond. Pour fonder un clan, gérer ses membres ou son territoire, tout est dans le [wiki des clans](/wiki/clans).

## Pour les clans

**Un seul sujet par clan**, ouvert par son chef ou un membre qui peut inviter. Garde-le à jour plutôt que d'en ouvrir un nouveau : réponds-y pour le faire remonter.

Titre : `[TAG] Nom du clan : recrute` (ou `complet`), puis :

```
Présentation : qui vous êtes, depuis quand
Ce que vous faites : (construction, commerce, exploration, farm...)
Nombre de membres :
Ce que vous cherchez : (profil, métier, horaires de jeu)
Ce que vous offrez : (base, ressources, entraide...)
Comment nous rejoindre : (pseudo à contacter en jeu)
```

Une capture de votre base donne envie !

## Pour les joueurs sans clan

Ouvre un sujet `Cherche un clan : ton pseudo` :

```
Pseudo :
Mon métier :
Ce que j'aime faire en jeu :
Quand je joue :
```

## Les règles

- Pas de messages pour **dénigrer** un autre clan.
- Les promesses faites ici n'engagent que ceux qui les font : le staff n'intervient pas dans les affaires internes d'un clan.
